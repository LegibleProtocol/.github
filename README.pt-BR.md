# Legible Protocol

Um padrão aberto para ampliar o universo legível e coordenável de inteligência.

Uma contribuição pode surgir antes de existir um projeto, uma equipe ou
um acordo de remuneração. O Legible oferece uma gramática comum para
preservar essas formulações, relacioná-las a outros trabalhos e reconhecer
consequências recebidas de sua utilização.

A proposta é ampliar o que pode ser encontrado, compreendido e considerado,
inclusive contribuições que não foram selecionadas inicialmente. Seus
registros podem circular entre ferramentas e contextos, apoiando a leitura
por pessoas e IAs.

## Uma gramática para contribuições

- Appoint: declara uma formulação, como um problema, uma hipótese,
  um critério ou uma solução.
- Trace: declara relações de dependência entre contribuições.
- Nod: reconhece uma consequência já recebida de uma contribuição.

Essa base comum permite examinar contribuições e suas relações. Quem
utiliza os registros escolhe como considerá-los e quais arranjos de
coordenação deseja construir.

## Explorar e contribuir

O projeto reúne uma especificação em rascunho e implementações experimentais,
abertas a revisão e experiências de uso.

Você pode contribuir com perguntas, críticas, relatos de experiências,
documentação, traduções ou código. Cada repositório apresenta suas licenças
e orientações para contribuição.
